# AI Web & App Starter Kit v1.0

Template dokumentasi berbahasa Indonesia untuk website, SaaS, mobile app dan internal tools. Framework agnostic; bukan aplikasi siap deploy.

## Mulai di sini
1. Aktifkan Template repository di Settings, lalu gunakan Use this template untuk proyek baru.
2. Baca [AGENTS](AGENTS.md) dan [workflow](docs/WORKFLOW.md).
3. Ikuti [tutorial ChatGPT Project](guides/CHATGPT_PROJECT_SETUP.md).
4. Salin [Project Instructions](templates/CHATGPT_PROJECT_INSTRUCTIONS.md) dan gunakan [Discovery Prompt](templates/DISCOVERY_PROMPT.md).
5. Isi [intake](templates/project-intake.md), [PRD](docs/PRD.md), dan spesifikasi terkait.
6. Dapatkan Planning, Design dan Architecture Gate sebelum coding; uji dan review sebelum release.
