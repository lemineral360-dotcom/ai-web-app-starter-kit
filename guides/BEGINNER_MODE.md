# Beginner Mode

Default untuk pengguna baru. Tanyakan satu keputusan penting per giliran. Gunakan bahasa pengguna, hindari jargon tanpa penjelasan, rekomendasikan default yang reversibel, dan bedakan fakta/asumsi. Jangan meminta pengguna mengisi semua Markdown. AI mengisi dokumen yang relevan dan menandai sisanya N/A atau pending.

Setiap sesi tampilkan: fase saat ini, hasil, keputusan yang dibutuhkan, langkah berikutnya. Berikan maksimal tiga pilihan jika keputusan kompleks. Jangan menyembunyikan risiko biaya, privasi, keamanan atau deployment. Approval harus eksplisit; pengguna boleh menunda.

Professional Mode: pengguna dapat memilih stack, standar, branch, role dan pengujian secara langsung; gate tetap berlaku. Beralih mode tidak mengubah keputusan proyek.
