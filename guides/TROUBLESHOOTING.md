# Bantuan pemula

| Masalah | Langkah |
|---|---|
| AI tidak bisa buka repo | Sambungkan akses atau unggah snapshot terbaru |
| AI lupa konteks | Minta baca HANDOFF dan TASKS dari branch aktual |
| Desain belum terlihat | Minta link artefak dan bukti; cek tool tersedia |
| Error coding | Berikan pesan error tanpa rahasia; minta diagnosis dan tes |
| Biaya tidak jelas | Minta estimasi dengan asumsi dan batas anggaran sebelum memilih layanan |
| Ingin revisi | Minta Change Request jika keputusan sudah approved |
| Ingin rilis | Minta release checklist dan bukti, jangan abaikan blocker |
