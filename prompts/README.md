# Prompt library

Baca AGENTS.md, PRD, TASKS, HANDOFF dan gate terkait sebelum tiap tugas.

| Fase | Prompt siap salin |
|---|---|
| Discovery | Interview saya bertahap; isi intake dan PRD, tandai asumsi, ajukan Planning Gate. |
| UX | Susun sitemap, user journey, screen inventory dan edge cases sesuai PRD. |
| Design | Susun tokens, typography, components, variants, accessibility dan responsive states; ajukan Design Gate. |
| Architecture | Bandingkan stack, rancang data/API/auth, deployment dan risiko; ajukan Architecture Gate. |
| Development | Verifikasi gate; pilih satu task, implementasikan acceptance criteria, jalankan tes. |
| QA | Uji critical journeys, permissions, error states, accessibility dan performance; catat bukti. |
| Release | Review backup, migration, rollback, monitoring dan persetujuan owner. |
| Handoff | Perbarui TASKS, HANDOFF, DECISIONS; ringkas bukti dan next step. |
