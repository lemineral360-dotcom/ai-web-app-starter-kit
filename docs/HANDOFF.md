## Instruksi AI berikutnya
1. Baca AGENTS.md, docs/CONSTITUTION.md, docs/PRD.md, docs/TASKS.md, docs/HANDOFF.md dan git log.
2. Verifikasi konteks serta status gate dari artefak aktual, jangan mengarang persetujuan.
3. Jika membuat proyek baru, isi intake/PRD dan jalankan Planning Gate dahulu.
4. Ketika berganti agen, catat progres, commit, pengujian, keputusan, blocker, dan next step.
5. Untuk perubahan besar setelah persetujuan, ajukan Change Request terlebih dahulu.
