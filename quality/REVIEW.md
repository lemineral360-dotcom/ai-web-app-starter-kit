# Review and refactoring
Creator supplies diff, approved scope, tests and artifact links. Reviewer independently checks acceptance, visual/UX, code, security and evidence. Record severity, reproduction, file, fix and retest. Refactor smallest necessary scope; preserve behavior with regression tests. Changes to approved scope require Change Request. For context, read AGENTS, current TASKS/HANDOFF, relevant specs and diff first; avoid loading every template. Audit duplicate rules and stale links before deleting. Beginner testing: observe a new user creating a repo, starting discovery, reviewing a gate and handing off; record actual friction and completion, never invent results.
