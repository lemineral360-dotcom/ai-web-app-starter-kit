# Anti AI Slop
Design: require product-specific direction, meaningful hierarchy, consistent tokens, realistic content, functional interactions and responsive evidence. Avoid decorative excess, not specific styles categorically.
UX: test core journeys and recovery; remove needless steps.
Code: inspect duplication, dead code, unnecessary dependencies, hardcoding, authorization and failure handling.
Documentation: maintain one canonical source per decision; remove stale duplicates only after checking references. Do not fill irrelevant templates.
Evidence: distinguish actual tests from plans and mockups. No fabricated results.
Review each change against acceptance criteria; prioritize blockers, fix and retest. Never claim zero AI slop.
