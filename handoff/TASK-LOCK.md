# Task ownership

Use GitHub issue assignment or owner-maintained TASKS.md. One active owner per task; no automatic distributed locking.

| Task | Agent/owner | Branch | Baseline SHA | Scope | Dependencies | Status | Claim time |
|---|---|---|---|---|---|---|---|

States: TODO → CLAIMED → IN PROGRESS → REVIEW → DONE; BLOCKED if needed. DONE requires accepted evidence and integration. Release claims when abandoning; owner resolves stale/duplicate claims. Never overwrite another claim. Shared files require integrator coordination.
